About SPMS

SPMS is a wearable-based posture monitoring system. It connects to an ESP32 sensor device through Bluetooth Low Energy (BLE) to provide posture monitoring, feedback and history.

  • Real-time posture monitoring
  • ESP32 and MPU6050 sensor integration
  • Posture alerts and history
  • English and Myanmar language support

How to install

  1. Tap Download APK and wait for the download to finish.
  2. Open the downloaded APK file.
  3. If prompted, allow your browser or file manager to install unknown apps.
  4. Install SPMS, then enable Bluetooth and connect your SPMS sensor.

Note: An SPMS ESP32 sensor device and Bluetooth Low Energy (BLE) support are required for posture monitoring.
